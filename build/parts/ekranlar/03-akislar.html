OyuncuHedef çubuğunu okur: "Otopark: 300/300 B · Ruhsat 3/3 · Sev. 3 ✓"

SistemÇubuk "Tapuyu al" düğmesine döner

Zaman · HUD≈ 70. dk · tam

2sokak

Oyuncu"Tapuyu Al (300 B)" → onay

SistemPOST /v1/businesses; cüzdan 300 → 0 B; 2 sn dönüşüm; durum "Kapalı — yazılım bekliyor"; KODLA! oku; LED: "Yeni tapu: @zeynep_cs — Çarşı"

Zaman · HUD≈ 71. dk

OyuncuKODLA! okuna tıklar

Zaman · HUD≈ 72. dk · odak

Zaman · HUD≈ 72–76. dk

Oyuncu"Kodlamaya Geç"

Zaman · HUD+ 2 dk

7.4 Akış 3 — Pazar → Dolap → Oda ziyareti

1meydan

OyuncuHUD'daki Pazar simgesine dokunur (yeni raf rozeti)

SistemPanel açılır, Bayt Rafları sekmesi

HUD / sesBayt 1.240 B

2pazar

Oyuncu"Kapüşonlu Hırka" (Şık, 220 B) kartına dokunur

SistemÖnizleme avatara giydirir; özet "Cüzdan: 1.240 B → 1.020 B"

HUD / sesui_tap

3pazar

Oyuncu[Satın Al] → onay modali → [Satın Al]

Sistempurchases; Bayt sayacı 1.240 → 1.020 sayarak düşer; toast "Kapüşonlu Hırka senin. Dolap'ta."

HUD / sescoin_spend

4pazar → dolap

Oyuncu[Dolap'a Git]

SistemDolap açılır, Kıyafet > Üst sekmesinde yeni öğe "Yeni" rozetli

HUD / ses—

5dolap

OyuncuHırkayı seçer, [Kaydet]

SistemÖnizleme güncellenir; sunucuya yazılır

HUD / sesui_confirm

6dolap → meydan

OyuncuKapatır; avatarı yeni hırkayla Meydan'da görür

SistemPodyum ve kalabalık hırkayı görür

HUD / ses—

7sohbet

OyuncuArkadaş listesinde @mert.k'yı seçer, [Odasına Git]

SistemOda izin modu "Herkese açık"; oda?oda=… ziyaretçi olarak açılır (sahibi çevrimdışı olabilir)

HUD / ses—

8oda

OyuncuStüdyo'yu gezer, Rozet Duvarı'na bakar, Ziyaretçi Defteri'ni açar

SistemSon 20 ziyaretçi; ayak izleri

HUD / ses—

9oda

Oyuncu[Alkışla]

SistemGünde 1; sahibine 2 B; toast "Alkışladın." (ilk kez ise ilk Alkış bonusu)

HUD / sesapplause

10oda → meydan

OyuncuKapıdan çıkar

SistemAynı hücreye dönüş; LED panoda ziyaret sayısı güncellenir

HUD / ses—
